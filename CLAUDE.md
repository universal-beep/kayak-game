# «Сплав на байдарке» — как вести работу

Общий регламент — `C:\Users\Admin\.claude\CLAUDE.md` (журнал, русские коммиты,
.bat/.ps1). Здесь — то, что относится к этому проекту.

## Просьбы, этапы, сторожа

Каждая просьба Максима — запись в `docs/requests.json`:
`id` (R001…), `date`, `ask`, `status` (todo / work / done), `result`,
`commits` (короткие хэши), `guards` (тесты-сторожа), `link`, `kind`, `verified`.

1. **Пришла просьба** — сразу запись со `status: "work"` и следующим `id`.
2. **Делаю** — красный тест первым. Этот тест и есть **сторож**: он падает,
   если исправление откатится. Название теста — по смыслу просьбы.
3. **Сделал** — `status: "done"`, `result`, `commits`, `guards` (названия
   тестов; `*` в конце — шаблон для тестов в цикле), `link: "руками"`.
   Просьба без кода (вопрос, коммит, отметка размера) — `kind: "без кода"`;
   ролики и голос — `kind: "промо"`. Им сторож не нужен.
4. **Максим проверил глазами** — `verified: "дд.мм.гггг"`.

Рисунки охраняет **замок рисунков** (`tests/sprite-lock.json`): любой спрайт,
изменившийся без `node tools/sprite-lock.mjs имя`, роняет тест
«рисунок не откатился: имя». `tools/sprite-apply.mjs` обновляет отпечаток сам.

## Перед отправкой на GitHub

`hooks/pre-push` → `node tools/guard.mjs`: все тесты; упавший файл
перезапускается (случайное падение — предупреждение); упал или пропал сторож
сделанной просьбы — **отправка стоит**, в выводе номер просьбы. Не обходить
(`--no-verify` — нельзя): чинить откат.

Установка хуков в новом клоне: `cp hooks/pre-push hooks/pre-commit .git/hooks/`.

## Ветки

- Работа — только в `art-pipeline`. `master` — копия для сайта:
  `git push origin art-pipeline` и `git push origin art-pipeline:master`
  (только перемотка вперёд, без `--force`).
- Облачные ветки (`claude/…`) — **не через pull request в master**. Сначала
  `git fetch` и `git merge origin/claude/…` в `art-pipeline` локально,
  сторож, потом отправка. 01.10.2026 три PR влились прямо в master — так
  больше не делать.
- **Перед крупной переделкой** (слой отрисовки, раскладка, больше ~100 строк)
  — метка: `git tag before-<что>-<ддммгггг>`. После — сторож и
  `git diff before-… -- index.html`: не пропало ли чужое исправление.
  Откаты 01–05.10 (полоска пути, название заставки, куст) были именно после
  переделок, не после слияний.
