## Принцип порядка

1. Сначала доверие: сохранения, один счёт, понятный провал. Это невидимо, но
   без этого остальное не имеет значения.
2. Потом первый опыт: учебный плёс, подсказки от действия, справка в паузе.
3. Потом выбор: гребок, развилка, баржа, день 3. Это меняет игру, а не оболочку.
4. Потом отклик: звук, hit stop, тряска, источник урона, пиксель.
5. Мобильный ввод и оболочка — после стабилизации ядра, отдельным плейтестом.
6. Мета — когда ядро честное.

Одна итерация = одна ветка = метка `before-<итерация>-<дата>` = красная проба
= `npm run lint` + `npm test` + `npm run analyze` = запись в журнал.
