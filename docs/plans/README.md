# Планы крупных переделок

Перед переделкой больше ~100 строк или целого слоя (отрисовка, раскладка,
расстановка жителей) — файл `ггггммдд-что.md`:

1. **Что меняется и зачем** — пара абзацев.
2. **Какие прежние просьбы задевает** — номера R… из `docs/requests.json`
   (доска: https://claude.ai/artifact/Dp7fuctjq7HrecmAX9wHMp) и их сторожа.
   Если у задетой просьбы сторожа нет — сначала написать.
3. **Как проверю** — какие тесты, что посмотреть глазами (десктоп и телефон).
4. После — метка `git tag before-…` уже стоит; сторож зелёный; `git diff`
   от метки просмотрен на пропавшие исправления.

Откаты 01–05.10.2026 (полоска пути, название заставки, куст, погоня у
велодороги) были именно после переделок без такого плана.
